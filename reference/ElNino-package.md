# ElNino: Lee, Resume y Grafica Datos Meteorológicos

Paquete hecho para la materia de programación II. Permite descargar los
datos de estaciones meteorológicas del repositorio de la materia,
calcular resúmenes de temperatura y precipitación por mes y estación, y
graficar la temperatura media mensual.
